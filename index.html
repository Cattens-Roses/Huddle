Huddle packages

Source: github.com/Cattens-Roses/Huddle

Debian / Ubuntu (apt)

echo "deb [trusted=yes] https://cattens-roses.github.io/Huddle ./" \
    | sudo tee /etc/apt/sources.list.d/huddle.list
  sudo apt update
  sudo apt install huddle

After that, system updates keep Huddle current. Rolling builds also publish to the beta GitHub release.
