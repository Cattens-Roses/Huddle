# baseapp

- Keep the app focused on its reusable desktop shell and UI appearance settings.
- Use the existing GPUI components and theme tokens from `crates/ui`.
- Keep user-facing copy clear and concise.
- Verify Rust changes with `cargo check -p baseapp`.
- After completing and verifying work, commit the task's changes and push them to GitHub. Leave unrelated working-tree changes out of the commit.
